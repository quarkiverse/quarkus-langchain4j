https://gemini.google.com/[Gemini] is a simpler platform designed for a broader audience than Vertex AI Gemini, including non-technical users.
It is a good first step for developers to get started with Gemini models.

== Using Gemini Chat Models

To use Gemini chat models, add the following dependency to your project:

:provider-artifact: quarkus-langchain4j-ai-gemini
include::./includes/quarkus-langchain4j-maven-dependencies.adoc[]

If no other LLM extension is installed, xref:ai-services.adoc[AI Services] will automatically utilize the configured Gemini model.

=== Configuration

Gemini requires an API key, which can be generated from the https://ai.google.dev/gemini-api/docs/api-key[Gemini platform].

Set the key in your `application.properties`:

[source,properties,subs=attributes+]
----
quarkus.langchain4j.ai.gemini.api-key=...
----

TIP: Alternatively, you can set the `QUARKUS_LANGCHAIN4J_AI_GEMINI_API_KEY` environment variable.

== Model Armor (Vertex AI Gemini)

With `quarkus-langchain4j-vertex-ai-gemini`, Vertex AI can screen prompts and responses with https://docs.cloud.google.com/security-command-center/docs/model-armor-vertex-integration[Model Armor]:

[source,properties]
----
quarkus.langchain4j.vertexai.gemini.chat-model.model-armor.prompt-template-name=projects/my-project/locations/europe-west4/templates/my-template
quarkus.langchain4j.vertexai.gemini.chat-model.model-armor.response-template-name=projects/my-project/locations/europe-west4/templates/my-template
----

* Enable the Model Armor API and grant `roles/modelarmor.user` to the Vertex AI service agent (`service-PROJECT_NUMBER@gcp-sa-aiplatform.iam.gserviceaccount.com`).
* Use templates in the same region as the configured `location`, otherwise the request fails with `Template not found`.
* Model Armor cannot be combined with `safetySettings`, which the extension does not send.
* Screening fails open: if Model Armor is unavailable, the request is not screened.

A blocked prompt or response raises an `IllegalArgumentException`; a blocked streamed response finishes with `CONTENT_FILTER`.
