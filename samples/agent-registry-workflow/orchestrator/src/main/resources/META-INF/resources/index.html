A registry-backed multilingual briefing

Discover and call the Weather MCP server → summarize over A2A → translate over A2A.

Endpoints come from Apicurio. Application code chooses the required roles and handoff order.

Try the governance story

While this page is running, use a second terminal from the repository root:

python3 samples/agent-registry-workflow/scripts/run.py --governance

Registry's BACKWARD compatibility rule rejects removal of the translation skill (HTTP 400). The command verifies that the accepted content and version remain unchanged, then runs the complete briefing again. It also publishes a compatible addition and demonstrates the new registration.

Local unauthenticated demonstration. Weather is fictional. Registry enforces compatibility on publication; the application does not implement compatibility rules or a deprecation gate. Registered versions are observations, not pinned remote deployments. Rejected metadata does not stop traffic to independently deployed code.
